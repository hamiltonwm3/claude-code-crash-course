What Output Styles Are

Output styles are custom response formatting configurations for Claude Code CLI. They shape how Claude communicates: the structure, tone, level of detail, and presentation style used in replies.

Think of them as reusable working modes. One style might keep answers tight and bullet-heavy. Another might produce YAML. A publishing style can turn article requests into complete HTML pages with a defined layout.

How They Work

Each output style appends instructions to Claude's system prompt. Those instructions become part of the assistant's operating context, so responses follow the style automatically while it is active.

+----------------------+     +----------------------+     +----------------------+
| Base Claude behavior | --> | Output style rules   | --> | Styled response      |
+----------------------+     +----------------------+     +----------------------+

The result is not just cosmetic. A style can influence whether Claude explains first, ships first, uses a specific file format, or follows a repeatable editorial structure.

Where Styles Live

Styles can be global or project-specific. Project styles take precedence, which makes them useful for team conventions and repository-specific workflows.

Global styles:   ~/.claude/output-styles/
Project styles:  {project}/.claude/output-styles/

File format:     Markdown with YAML frontmatter
Required field:  description
Precedence:      Project > Global

"A good output style removes tiny repeated decisions. It lets the work start closer to finished."

Example Styles

Here are common styles you might see in a Claude Code setup, including the retro HTML publishing style used for this page.

default
Standard Claude behavior with no special response structure.
minimal-bullets
Concise bullet-point responses designed for quick scanning.
yaml-concise
Structured minimal responses formatted as YAML.
retro-ascii-blog
Complete HTML pages with ASCII-art inspired blog styling.

Command Reference

Use the output-style command menu to inspect, switch, or create styles inside Claude Code.

/output-style          List available styles
/output-style {name}   Switch to a specific style
/output-style:new      Create a new style

What Styles Can Control

  • Response format: bullets, YAML, HTML, prose, or another repeatable structure.
  • Communication tone: formal, casual, technical, educational, terse, or editorial.
  • Information density: concise answers, detailed walkthroughs, or comprehensive references.
  • Task approach: whether to prioritize speed, thoroughness, teaching, or production-ready output.
  • Workflow habits: how much explanation to include and when to provide deliverables.
